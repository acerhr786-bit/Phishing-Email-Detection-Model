    Core Cybersecurity Rules for Email Security

    1. Inspect Links Before Clicking

    Hover over hyperlinks to preview the actual destination URL. Attackers frequently disguise malicious domains behind reassuring button labels.

    2. Beware of Artificial Urgency

    Phrases like "Within 24 Hours", "Immediate Suspension", or "Wire Transfer Required" are psychological tricks designed to induce panic.

    3. Out-of-Band Verification

    If an email requests sensitive changes (payroll accounts, wire instructions, or gift cards), call the sender using a known, trusted corporate phone number.

    4. Zero-Trust for "Safe" Scores

    Machine learning models look for statistical patterns. Novel zero-day attacks or compromised internal accounts require human critical thinking.
